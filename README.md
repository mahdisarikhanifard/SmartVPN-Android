# SmartVPN Android

نسخه آغازین پروژه اندرویدی SmartVPN با Kotlin و Android SDK.

## وضعیت فعلی 0.1.0
- ساختار پایه Android/Kotlin
- رابط اولیه فارسی
- انتخاب فایل محلی و شناسایی اولیه URIهای VLESS، VMess، Trojan، Shadowsocks، Hysteria2، TUIC و قالب WG (فقط تشخیص متنی)
- نمایش نرخ تقریبی دریافت/ارسال کل دستگاه با Android TrafficStats
- GitHub Actions برای ساخت APK آزمایشی

## مواردی که هنوز پیاده‌سازی نشده‌اند
- موتور تونل VPN واقعی و ادغام sing-box/libbox
- واکشی خودکار منابع عمومی کانفیگ
- اعتبارسنجی امن و تست اتصال هر کانفیگ
- انتخاب خودکار سرور و تعویض هنگام قطعی
- سنجش سرعت اختصاصی داخل تونل

**این نسخه هنوز فیلترشکن عملیاتی نیست.** سرعت نمایش‌داده‌شده ترافیک کل دستگاه است، نه سرعت اختصاصی VPN. کانفیگ‌های عمومی ناشناس را وارد نکنید مگر اینکه به منبع اعتماد داشته باشید؛ کانفیگ می‌تواند ترافیک شما را از سرور شخص ثالث عبور دهد.

## Build
GitHub Actions با JDK 17 و Gradle 8.9 فایل APK آزمایشی را می‌سازد.
