# SmartVPN Android

برنامه اندرویدی SmartVPN با Kotlin و موتور پایه sing-box/libbox.

## نسخه 0.3.0

- نگهداری محلی کانفیگ‌های واردشده پس از بستن برنامه
- ورود لینک یا چندخطی کانفیگ و فایل متنی
- ورود اشتراک از URL فقط با HTTPS
- تشخیص اولیه لینک‌های VLESS، VMess، Trojan، Shadowsocks، Hysteria2، TUIC و WireGuard
- حذف کانفیگ‌ها از فهرست
- آزمایش دسترس‌پذیری TCP میزبان/پورت و مرتب‌سازی نتایج بر اساس زمان پاسخ
- نمایش ترافیک کلی دستگاه از طریق Android TrafficStats
- اضافه‌شدن وابستگی libbox نسخه 1.14.0 به پروژه و تأیید موفقیت دریافت و کامپایل آن در GitHub Actions

## وضعیت فنی مهم

**نسخه 0.3.0 هنوز VPN عملیاتی نیست.** اضافه‌شدن کتابخانه libbox به‌تنهایی موتور VPN را فعال نمی‌کند. پیاده‌سازی و اتصال Android `VpnService`، رابط `PlatformInterface`، راه‌اندازی `CommandServer`، آماده‌سازی تنظیمات libbox و تبدیل کانفیگ‌های URI به پیکربندی معتبر sing-box هنوز انجام نشده‌اند. بنابراین دکمه اتصال نباید وضعیت اتصال جعلی نمایش دهد و این نسخه را نباید به‌عنوان VPN قابل استفاده معرفی کرد.

آزمایش فعلی فقط بررسی می‌کند که میزبان و پورت کانفیگ از طریق TCP قابل دسترسی هستند؛ این آزمایش اعتبارنامه، handshake پروتکل، کیفیت واقعی مسیر یا امکان عبور ترافیک از VPN را تأیید نمی‌کند.

سرورهای عمومی ناشناس می‌توانند ترافیک را مشاهده یا دستکاری کنند. از اشتراک‌ها و کانفیگ‌هایی استفاده کنید که منبع آن‌ها را می‌شناسید. دریافت اشتراک در برنامه فقط از HTTPS مجاز است.

## ساخت

GitHub Actions با JDK 17 و Gradle 8.9 فایل APK آزمایشی را در artifact با نام `SmartVPN-debug` منتشر می‌کند.
