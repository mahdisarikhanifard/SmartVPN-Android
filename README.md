# SmartVPN Android

کلاینت اندرویدی مبتنی بر Kotlin و موتور بومی sing-box/libbox 1.14.4.

## نسخه 0.5.1

- رفع کرش شروع برنامه به دلیل مقداردهی‌نشدن کانتینر فهرست سرورها در صفحه اصلی.

## نسخه 0.5.0

- صفحه اصلی ساده با دکمه «اتصال» و فرایند انتخاب خودکار سرور
- دریافت فهرست عمومی سرورها از منبع HTTPS قابل تغییر در تنظیمات
- آزمایش TCP هم‌زمان تعداد محدودی از سرورها و مرتب‌سازی بر اساس تأخیر
- امتحان پیاپی گزینه‌های رتبه‌بندی‌شده در صورت شکست راه‌اندازی یا آزمون عبور اینترنت
- انتقال ورود دستی لینک/متن/فایل و اشتراک به بخش تنظیمات
- آزمون اتصال اینترنت از داخل تونل پیش از اعلام وضعیت متصل

این حالت خودکار از یک فهرست عمومی ثالث استفاده می‌کند؛ این سرورها رایگان، ناشناس و غیرقابل اعتمادند. آزمون TCP فقط دسترسی پورت را می‌سنجد و رتبه‌بندی نهایی واقعی نیازمند آزمون تونل روی خود گوشی است. آزمون اینترنت از چند مقصد HTTPS استفاده می‌کند و ممکن است در شبکه‌هایی که آن مقصدها مسدودند، اتصال واقعی را تأیید نکند.

## نسخه 0.4.0

- نگهداری محلی پروفایل‌ها و ورود لینک/متن/فایل و اشتراک HTTPS
- ساخت پیکربندی sing-box برای لینک‌های VLESS، VMess، Trojan، Shadowsocks، Hysteria2 و TUIC
- پشتیبانی اولیه از لینک WireGuard با پارامترهای لازم
- امکان واردکردن فایل JSON کامل sing-box
- سرویس Android `VpnService` با مجوز سیستمی VPN، اعلان foreground و مسیر اتصال/قطع
- ایجاد TUN از طریق `VpnService.Builder` و راه‌اندازی `CommandServer` از libbox
- محافظت سوکت‌های خروجی از تونل VPN و ارائه فهرست رابط‌های شبکه به موتور
- نگهداری پروفایل‌ها به‌صورت محلی و نمایش latency آزمون TCP

## محدودیت‌های مهم نسخه

این نسخه نخستین ادغام اجرایی libbox است و هنوز باید روی دستگاه واقعی با کانفیگ‌های معتبر و شبکه‌های مختلف آزمایش شود. موفقیت GitHub Actions فقط کامپایل و بسته‌بندی APK را تأیید می‌کند؛ به‌تنهایی اتصال موفق به سرور، عبور کامل IPv4/IPv6، جلوگیری قطعی از نشت DNS، عملکرد پایدار در پس‌زمینه یا سازگاری همهٔ پارامترهای پروتکل‌ها را ثابت نمی‌کند.

پشتیبانی از لینک WireGuard به قالب لینک دارای پارامترهای `private_key`، `peer_public_key`، `address` و `server_port` محدود است؛ فایل‌های متداول wg-quick هنوز به مبدل جداگانه نیاز دارند. کانفیگ‌های اشتراک ممکن است فرمت‌های اختصاصی یا پارامترهای خاص داشته باشند و قبل از استفاده باید بررسی شوند.

آزمایش TCP صرفاً دسترسی میزبان و پورت را می‌سنجد و معادل handshake یا سنجش کیفیت تونل نیست. ترافیک نمایش‌داده‌شده در صفحهٔ اصلی، آمار کل دستگاه است و نباید به‌عنوان آمار اختصاصی VPN تفسیر شود.

کانفیگ‌های عمومی ناشناس می‌توانند ناامن یا مخرب باشند. فقط از منابع قابل اعتماد استفاده کنید.
